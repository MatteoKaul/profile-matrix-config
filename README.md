# profile-matrix-config

Source of **profile-matrix**: dot-matrix (LED) GitHub profile READMEs,
generated by GitHub Actions from one `settings.txt`.

- **Editor:** https://matteokaul.github.io/profile-matrix-config/
  Design a profile in the browser and download its `settings.txt`.
  Nothing leaves the browser.
- **Template:** [MatteoKaul/profile-matrix](https://github.com/MatteoKaul/profile-matrix)
  Copy it with "Use this template", upload your `settings.txt`, done.
  Its README has the four steps.

## This repository

```
scripts/   fonts/        renderer and generator (shared by editor and workflows)
editor/                  web editor, published to GitHub Pages
template/                files only the template gets (README, workflows)
default.settings.txt     neutral example, used until a settings.txt exists
tools/export.mjs         builds the template or the Pages site
tools/check.mjs          checks run before every release
tools/counter/           optional self-hosted visitor counter
.github/workflows/release.yml   version, Pages, push to profile-matrix
```

Every push to `main` with a `feat:`, `fix:`, `perf:` or `refactor:` commit
releases a new version: the editor goes to Pages and the generator to
`profile-matrix` (same version tag in both). Commit messages follow
[Conventional Commits](https://www.conventionalcommits.org/).

## Working on it

```sh
node tools/check.mjs                  # everything the release checks
python3 -m http.server 8000           # editor at http://localhost:8000/editor/
node tools/export.mjs template /tmp/pm && cd /tmp/pm && node scripts/build.mjs --sample
```

Node 18+ only, no dependencies. Details: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md),
status and open points: [HANDOFF.md](HANDOFF.md).
