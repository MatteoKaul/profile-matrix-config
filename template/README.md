# profile-matrix

A GitHub profile README in a dot-matrix (LED) style, generated by GitHub
Actions from one settings file. You design it in the browser; this
repository only builds it.

**Editor:** https://matteokaul.github.io/profile-matrix-config/

## Get your profile in four steps

1. **Use this template** (green button, top right) -> **Create a new repository**.
   Name it exactly like your GitHub username (e.g. `octocat/octocat`) and make it
   **public**, then GitHub shows its README on your profile.
2. Open the [editor](https://matteokaul.github.io/profile-matrix-config/), click
   your profile together and press **Download settings.txt**. Everything happens
   in your browser; nothing is sent anywhere.
3. In your new repository: **Add file** -> **Upload files**, drop `settings.txt`
   (plus your own images into `assets/src/`, if you used any) and commit to `main`.
4. The **Update profile** workflow starts by itself and replaces this README with
   your profile within about a minute (tab **Actions**). After that it runs
   daily, and again whenever you upload a new `settings.txt`.

Until you upload a `settings.txt`, the workflow builds a neutral example from
`default.settings.txt`.

## Modules that need a key

Steam, the portfolio tracker (except provider `yahoo`) and the Twitch live card
read API keys. Keys never go into `settings.txt`: this repository is public.
Store them as **repository secrets** in your repository:
**Settings** -> **Secrets and variables** -> **Actions** -> **New repository secret**.

| Secret | Module |
|---|---|
| `STEAM_API_KEY` | steam |
| `MARKET_API_KEY` | portfolio (tiingo, eodhd, alphavantage, stooq) |
| `TWITCH_CLIENT_ID`, `TWITCH_CLIENT_SECRET` | twitch |

The editor has a step-by-step guide (**Secrets guide**, top bar).

## What is in here

| Path | |
|---|---|
| `settings.txt` | your settings (you upload it) |
| `default.settings.txt` | neutral fallback, do not edit |
| `scripts/`, `fonts/` | the generator |
| `.github/workflows/profile.yml` | daily build: fetch data, render, commit |
| `.github/workflows/live.yml` | optional 10-minute Twitch check (off by default) |
| `tools/counter/` | optional self-hosted visitor counter |
| `assets/gen/`, `data/` | written by the workflow, do not edit |
